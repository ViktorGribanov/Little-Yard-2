# Little Yard — landing site

A landing page for a small countryside house-rental business (four houses, a fifth planned), built so the owner can edit content himself without touching code, and so the site shows up when people search for the place.

## Current stage: planning (no code yet)

This project is at the documentation/planning stage. No Astro project, no CMS config, and no deployment exist yet. The next step is building a Phase 1 clickable prototype (see `REQUIREMENTS.md` §4) once this documentation is reviewed.

Per the current working agreement, no application code is written, no dependencies are installed, no external services are signed up for, and nothing is published until this is explicitly approved.
